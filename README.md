Vice Cover Studio turns your own photos and a caption into GTA-style multi-panel cover art — three poster layouts, four sunset and neon colour grades, per-panel crop and positioning, and one-tap PNG export in square, portrait and wide post sizes. It runs fully offline in the browser and never uploads your photos.

## Run it

```sh
node serve.ts
```
